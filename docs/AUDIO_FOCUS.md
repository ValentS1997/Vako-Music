# Audio Focus для музыки и видео

Аудио в `PlaybackService` и видео в Media3 запрашивают системный Audio Focus с атрибутами `USAGE_MEDIA`. Запуск видео получает фокус и ставит музыку на паузу. После закрытия видео фокус освобождается; музыка не возобновляется сама после постоянной потери фокуса. Ручная пауза пользователя также запрещает автоматическое возобновление. Временное прерывание музыки может возобновить её только если она играла до прерывания; при duck громкость понижается и затем восстанавливается. В PiP видео продолжает владеть фокусом, пока играет.

## Частичная проверка 2026-11-21

- Устройство: realme RMX5303, Android API 36. Тестовый debug APK SHA-256: `258161ffcc582a32d0329d82619be79223d3f59e78677f8496feb5b43dd8ea0e`.
- Системная медиасессия музыки была в состоянии `PLAYING`. После запуска локального видео `VideoPlayerActivity` перешла в foreground, медиасессия музыки стала `PAUSED`, верхний элемент системного Audio Focus stack принадлежал Media3 ExoPlayer с `CONTENT_TYPE_MOVIE`.
- После Back главный экран вернулся, Audio Focus stack стал пустым, музыка осталась на паузе.
- Звонок, Bluetooth, гарнитура, навигация, сторонний плеер и PiP в этой проверке — **NOT RUN**. Результаты относятся только к указанному устройству и сборке.
