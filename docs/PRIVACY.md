# Конфиденциальность

Vako Music — локальное Android-приложение. В версии 0.0.1 нет собственной серверной части, рекламных SDK или аналитики. Приложение не отправляет список локальных файлов владельцу проекта.

## Какие данные используются

| Данные | Для чего | Где хранятся |
| --- | --- | --- |
| Аудио и видео телефона, карты памяти | Медиатека и воспроизведение | Читаются через MediaStore; сами файлы остаются на устройстве. |
| Настройки, плейлисты, очередь, история | Восстановление состояния | Локальные данные приложения (`SharedPreferences`). |
| OAuth-токен Яндекс Музыки | Доступ к выбранному пользователем аккаунту | На устройстве, в зашифрованном виде; ключ находится в Android Keystore. |
| Загруженные треки | Воспроизведение обычными плеерами | Общая музыкальная папка устройства `Music/MusicDownloader`. |

Модуль Яндекс Музыки обращается к `api.music.yandex.net`, серверам обложек и адресам загрузки, выданным сервисом. Токен передаётся Яндексу через HTTPS в заголовке запроса. Внешняя ссылка на инструкцию получения токена (`ym.marshal.dev`) открывается только по нажатию пользователя в браузере; это отдельный сайт со своей политикой данных. Сетевые возможности Яндекса можно отключить в настройках приложения.

## Разрешения Android

- `READ_MEDIA_AUDIO` / `READ_EXTERNAL_STORAGE` на старых версиях: чтение локальной музыки.
- `READ_MEDIA_VIDEO`: чтение локального видео.
- `RECORD_AUDIO`: захват данных аудиосеанса для визуализации. Приложение не записывает микрофон в файл.
- `INTERNET`: Яндекс Музыка, обложки и загрузка файлов.
- `FOREGROUND_SERVICE` и `FOREGROUND_SERVICE_MEDIA_PLAYBACK`: продолжение аудио и управление из уведомления.

Разрешения на медиа и визуализацию запрашиваются системными диалогами при использовании соответствующей функции. Чтобы удалить токен и локальные настройки, отключите аккаунт в приложении или очистите данные Vako Music в системных настройках Android. Загруженные в общую папку треки при очистке данных приложения остаются на устройстве и удаляются отдельно.
