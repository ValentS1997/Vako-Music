# Первый проход редизайна интерфейса

Дата: 20 ноября 2026 года. Основа: `codex/ui-redesign-plan` (`d941d645`). Этот проход реализует визуальную основу из [оценки](UI_REDESIGN_ASSESSMENT.md); новая логика воспроизведения и сетевых операций в него не входит.

## Что сделано

- Добавлены общие радиусы для компонентов Compose, компактные вкладки, поле поиска и заголовок раздела. Цвета берутся из действующей пользовательской палитры.
- Обновлены поверхности строк медиатеки, папок, плейлистов, Яндекс Музыки, очереди, видео и настроек. Выбранные элементы выделяются цветом текущей темы.
- Нижние разделы и мини-плеер получили округлые поверхности. Короткое нажатие на нижний раздел обработано отдельным `clickable`; перетаскивание разделов сохранено.
- В полноэкранном аудиоплеере увеличена основная кнопка воспроизведения. В видеоплеере округлены панель и накладки управления без изменения размера кадра.
- Действия экспорта и удаления локальной автоподборки визуально разделены.

## Проверка

- `./gradlew :app:assembleDebug :app:lintDebug :app:testDebugUnitTest --offline` с JDK 17 и Android SDK: успешно.
- RMX5303, 720 × 1604, Android через USB/ADB: `adb install -r` успешно, данные приложения сохранены. Проверены загрузка медиатеки с 7937 файлами, переходы между нижними разделами, вкладка папок, экран настроек, поиск Яндекс Музыки, видеобраузер с 2817 файлами и открытие полноэкранного аудиоплеера.
- Дополнительный проход на RMX5303: белая и серая палитры отображаются корректно; исходная чёрная палитра с зелёным акцентом восстановлена. При системном масштабе шрифта 1,5 обнаружено обрезание второй строки трека и нижних вкладок. Высота строк сделана гибкой, а на узком экране или при крупном шрифте нижние вкладки используют короткие видимые подписи с полными доступными названиями. Повторная проверка при 1,5 прошла; масштаб телефона возвращён к 1,0.
- Временный размер экрана 544 × 1210 пикселей при плотности 272 dpi (320 dp по ширине): медиатека загрузила 7937 файлов, строки и нижняя навигация уместились. Исходный размер 720 × 1604 восстановлен. Очередь из 100 элементов просмотрена без изменения порядка.
- Очередь и 105 пользовательских плейлистов Яндекс Музыки проверены при масштабе шрифта 1,5. Добавлены внутренние отступы для двухстрочных карточек; повторный просмотр показал обе строки без обрезания.
- Перетаскивание нижних разделов проверено через последовательность ADB `DOWN` → удержание → `MOVE` → `UP`: порядок изменился, затем восстановлен. Короткое нажатие на разделы продолжает работать.
- Для кнопки очистки поиска и стрелок очереди добавлены понятные названия действий для средств доступности.
- Видеоплеер открылся в альбомной ориентации; при переходе на главный экран видео осталось в системном окне «картинка в картинке» с доступными системными действиями. После проверки приложение закрыто и снова запущено. Закрытие PiP экранным крестиком через ADB осталось непроверенным.
- Личные скриншоты устройства хранятся только во временных локальных файлах и не публикуются.

## Следующие визуальные проверки

- Пользовательская HEX-палитра и сочетания с низким контрастом.
- Перетаскивание в длинной очереди и TalkBack.
- Видеоплеер в альбомной ориентации и режиме «картинка в картинке».

Остальные особенности из макетов — отдельная нижняя вкладка очереди, встроенный видеоплеер, кроссфейд и вымышленные обложки — не входили в согласованное направление.
