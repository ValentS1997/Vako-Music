# Использование ИИ при разработке

В разработке Vako Player используются инструменты ИИ, в том числе Codex, для подготовки кода, переработки интерфейса, исследования функций других плееров и написания документации. Пользовательские требования, приоритеты, тестирование на реальном устройстве и решение о публичном выпуске остаются за владельцем проекта.

Результаты ИИ проходят просмотр исходников, сборку Gradle, Android Lint и выборочные проверки на телефоне RMX5303. Эти проверки не заменяют независимый аудит безопасности, лицензий, совместимости устройств и поведения недокументированного API Яндекс Музыки. Известные границы проверки фиксируются в [CHANGELOG](../CHANGELOG.md) и [AUDIT_HANDOFF](AUDIT_HANDOFF.md).

Токены и данные личной медиатеки не должны попадать в запросы для ИИ, коммиты и публичные отчёты. Скриншоты устройства использовались только локально для проверки интерфейса и в репозиторий не включаются.
