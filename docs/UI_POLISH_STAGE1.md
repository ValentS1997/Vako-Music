# UI Polish Pack v1.1: первый этап

Основа: `codex/ui-redesign-implementation` (`852765ef`). Пакет: `VAKO-MUSIC-UI-POLISH-PACK-v1.1`, контрольные суммы проверены по `SHA256SUMS.txt`. Этот этап касается общих компонентов Compose и контраста предустановленных тем.

## Реализовано

- Введён общий статичный эффект поверхности: лёгкий градиент, тонкая рамка и небольшая тень только у выбранных элементов. Цвета берутся из текущей палитры; списки треков не получают дополнительных теней.
- Выбранные вкладки стали заметнее, поле поиска получило мягкую заливку и акцентную рамку при фокусе. Минимальная высота вкладки — 48 dp.
- При вычислении предустановленной темы приглушённый текст подбирается с контрастом не ниже 4,5:1 на обычной и слегка отличающейся поверхности. Для пользовательского HEX-цвета, который сам не даёт нужного контраста, значение сохраняется без автоматической замены.

## Проверка

- `:app:assembleDebug`, `:app:lintDebug`, `:app:testDebugUnitTest` с JDK 17 и Android SDK — успешно.
- Тест охватывает 3 основы × 8 акцентов: обычный текст, приглушённый текст, основную кнопку и верхнюю точку блика выбранного элемента.
- RMX5303 через ADB: установка поверх существующей версии без удаления данных; приложение открылось, медиатека загрузила 7937 файлов. В текущей тёмной теме вкладки и поиск отображаются корректно, ошибок приложения в журнале не обнаружено.
- Снимки экрана и содержимое медиатеки оставлены только во временных локальных файлах, в репозиторий не добавлены.
