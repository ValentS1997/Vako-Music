## Частичная проверка на RMX5303

- Устройство: realme RMX5303, Android API 36; тестовая сборка APK SHA-256 `f75cf4b8850a56ecb3c0520586dc2e62b9b37da46b6b2bbf422d8b5627fdc29a`.
- Установка через `adb install -r` прошла успешно поверх предыдущей отладочной версии, данные сохранились. Приложение открыло медиатеку из 7937 файлов и прежнюю очередь.
- Системные команды `cmd media_session dispatch play` два раза подряд оставили `RikkoPlayback` в состоянии PLAYING; два вызова `pause` оставили его в PAUSED. Это проверено при открытом приложении. Управление из шторки и гарнитуры отдельно не проверено.
- Таймер на 15 минут был включён, после Home и возврата в Activity оставался активным (пункт «Отменить таймер» присутствовал); после проверки отменён. Истечение таймера, блокировка телефона и пересоздание Activity отдельно не проверены.
- Не выполнялись изменения пользовательских файлов, реальные загрузки и проверка Audio Focus с другим приложением.

Для Audio Focus ожидается: при постоянной потере фокуса музыка ставится на паузу; при временной потере воспроизведение возобновляется только если до прерывания играло; при duck громкость понижается до 20% и затем восстанавливается. Пользовательская пауза запрещает автоматическое возобновление.

Таймер сна хранится в `PlaybackService` по монотонному времени и продолжает отсчёт при пересоздании Activity, пока жив сервис. После завершения процесса таймер не восстанавливается; при следующем запуске он выключен.

Повреждённый аудиофайл или ошибка публикации в MediaStore должны оставлять сообщение об ошибке и не оставлять видимый частичный файл. При частичном успехе массового изменения интерфейс показывает число выполненных и невыполненных файлов и предлагает повторить только неуспешные.
