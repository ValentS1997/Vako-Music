# Проверка стабилизации после аудита

Автоматический gate: `./gradlew testDebugUnitTest assembleDebug lintDebug`. Отчёт unit-тестов сохраняется в CI artifact `unit-test-results`.

Устройства в таблице ниже **не проверены** для этой ветки. Статус PASS ставится только после фактического испытания с моделью, версией Android, SHA сборки и результатом.

| Сценарий | Android 10 | Android 11 | Android 13 | Android 14+ |
| --- | --- | --- | --- | --- |
| Системные Play/Pause повторно, шторка, гарнитура | NOT RUN | NOT RUN | NOT RUN | NOT RUN |
| Audio Focus: другое приложение, звонок, ассистент, Bluetooth | NOT RUN | NOT RUN | NOT RUN | NOT RUN |
| Таймер при блокировке, уходе из приложения и пересоздании Activity | NOT RUN | NOT RUN | NOT RUN | NOT RUN |
| MP3/FLAC, обрыв сети, превышение лимита, повторная загрузка | NOT RUN | NOT RUN | NOT RUN | NOT RUN |
| Массовый перенос: частичный успех, повтор, отзыв доступа | NOT RUN | NOT RUN | NOT RUN | NOT RUN |
| Память телефона и SD-карта, копирование и переименование | NOT RUN | NOT RUN | NOT RUN | NOT RUN |
| Видео: жесты, фон и «картинка в картинке» | NOT RUN | NOT RUN | NOT RUN | NOT RUN |

Для Audio Focus ожидается: при постоянной потере фокуса музыка ставится на паузу; при временной потере воспроизведение возобновляется только если до прерывания играло; при duck громкость понижается до 20% и затем восстанавливается. Пользовательская пауза запрещает автоматическое возобновление.

Таймер сна хранится в `PlaybackService` по монотонному времени и продолжает отсчёт при пересоздании Activity, пока жив сервис. После завершения процесса таймер не восстанавливается; при следующем запуске он выключен.

Повреждённый аудиофайл или ошибка публикации в MediaStore должны оставлять сообщение об ошибке и не оставлять видимый частичный файл. При частичном успехе массового изменения интерфейс показывает число выполненных и невыполненных файлов и предлагает повторить только неуспешные.
