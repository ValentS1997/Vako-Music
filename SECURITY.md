# Безопасность

Поддерживаемая публичная версия: **0.0.2**.

Если вы обнаружили утечку токена, уязвимость в хранении данных или возможность несанкционированного изменения файлов, сообщите владельцу **приватно** через [Security Advisories репозитория](https://github.com/ValentS1997/Vako-Music/security/advisories/new), если GitHub предоставляет эту форму. Не публикуйте токены, реальные медиафайлы, персональные пути или подробный сценарий эксплуатации в открытом issue.

В сообщении укажите версию приложения, модель устройства, версию Android, шаги воспроизведения и возможное влияние. Для обычных ошибок интерфейса используйте публичные issue без личных данных.

OAuth-токен Яндекс Музыки сохраняется на устройстве с шифрованием Android Keystore. Не вставляйте токены в логи, скриншоты, отчёты или pull request. Если токен раскрыт, отзовите его на стороне провайдера и подключите аккаунт заново.
