## Что подходит Рикко

Оценка трудоёмкости дана для текущего приложения на `MediaPlayer`, Compose и `MediaStore`.

| Функция | Польза | Трудоёмкость | Решение |
| --- | --- | --- | --- |
| Дерево папок и подпапок | Совпадает с привычной навигацией по файлам | Низкая | Реализовано в 0.6.0; требуется проверка на RMX5303. |
| Сортировка треков и папок по имени, исполнителю, дате | Делает большую медиатеку управляемой | Низкая | Реализовано в 0.7.0. |
| «Воспроизвести папку» и «Добавить папку в очередь» | Убирает необходимость открывать каждый трек | Низкая | Реализовано в 0.7.0. |
| Избранное и «Недавно добавленные» | Быстрый доступ без ручных плейлистов | Низкая–средняя | Хранить избранное по URI, дату брать из MediaStore. |
| Сохранение очереди и позиции | Возврат к прослушиванию после закрытия приложения | Средняя | Реализовать вместе с фоновым плеером. |
| Таймер сна | Востребован при прослушивании перед сном | Средняя | Базовый таймер в 0.7.0; для гарантированной работы в фоне нужен сервис. |
| Обложки альбомов | Улучшают ориентацию в списках и экран трека | Средняя | Обложка текущего трека в 0.7.0; сетку изображений можно добавить отдельно. |
| Тексты песен, включая LRC | Полезно в полноэкранном плеере | Средняя | Сначала локальные встроенные тексты и LRC, затем доступные данные Яндекса. |
| Импорт и экспорт M3U | Перенос плейлистов между плеерами | Средняя | Учесть URI Android и относительные пути карты памяти. |
| Фоновое воспроизведение, экран блокировки, Bluetooth | Базовое поведение музыкального приложения | Высокая | Приоритетная архитектурная задача: перенести плеер в `MediaSessionService`. [Рекомендация Android](https://developer.android.com/media/media3/session/background-playback). |
| Эквалайзер | Настройка звучания | Средняя–высокая | Базовые полосы Android в 0.7.0; проверять на конкретных устройствах. |
| Gapless, crossfade, ReplayGain | Плавное и ровное звучание | Высокая | Рассматривать вместе с переходом на Media3/ExoPlayer. |
| Сложные визуализации уровня MilkDrop | Ностальгический эффект | Высокая | Текущие три стиля оставить лёгким вариантом; новые стили требуют отдельного графического модуля. |

## Рекомендуемый порядок

1. Проверить дерево папок на телефоне, включая карту памяти и кнопку Android «Назад».
2. Добавить сортировку, воспроизведение всей папки и избранное. Эти функции не требуют замены аудиодвижка и сохраняют компактный интерфейс.
3. Перенести воспроизведение в `MediaSessionService`, добавить уведомление, управление с экрана блокировки и гарнитуры.
4. После этого реализовать таймер сна, восстановление очереди и обложки.
5. Отдельно решить, нужны ли эквалайзер, тексты песен и импорт плейлистов.

Интеграция с Яндекс Музыкой опирается на недокументированный API. Новые действия, меняющие данные аккаунта, требуют проверки ответов сервиса и обработки конфликтов версий плейлиста.
