# Видео в Vako Music: обзор MX Player Pro

Проверено 17 ноября 2026 года на RMX5303: установленный MX Player Pro, его список файлов, меню просмотра и настройки «Плеер → Управление». Дополнительно сверены [официальная справка MX Player по интерфейсу](https://support.mxplayer.in/support/solutions/folders/43000574905), [справка по субтитрам](https://support.mxplayer.in/support/solutions/folders/43000574904) и [справка Android Media3 по форматам](https://developer.android.com/media/media3/exoplayer/supported-formats).

| Механика MX Player Pro | Решение для Vako Music 0.15.0 |
| --- | --- |
| Папки и файлы, переход в подпапки | Вкладка «Видео»: накопители → папки → подпапки → файлы; отдельный общий список |
| Сортировка по имени, дате, длительности, размеру | Четыре варианта сортировки |
| Полноэкранный плеер и полоса перемотки | Отдельный экран Media3 с системными контролами |
| Продолжить с места остановки | Позиция сохраняется по URI, при повторном открытии предлагается продолжить |
| Скорость и масштаб | 0,5–2×; вписать, заполнить, увеличить |
| Внешние субтитры | Выбор файла SRT или VTT через системный диалог |
| Картинка в картинке | Кнопка в плеере, если устройство поддерживает PiP |
| Жесты | Двойное касание слева/справа перематывает на 10 секунд, в центре переключает паузу; вертикальный свайп слева меняет яркость, справа — громкость |

Версия 0.16.0 добавила временные 2× при удержании, отдельную громкость видео, автоматический поворот, автоматическое маленькое окно, видеоплейлисты и операции с видеофайлами. В MX Player Pro также есть выбор аудиодорожки, настройка синхронизации субтитров, список продолжения, сетка, сетевые источники и выбор декодера. Это кандидаты для следующих выпусков. Текущая версия использует декодеры Android через Media3; доступность конкретных кодеков зависит от устройства. Режимы HW+/SW MX Player не копируются.

Видео сканируется только после отдельного системного разрешения Android. Раздел можно отключить в «Настройки → Разделы приложения». Отдельный файл открывается и без разрешения через системный выбор документа.

## Требования версии 0.17.0 — записано 17 ноября 2026

1. **Яркость только в Vako Music.** Свайп слева должен изменять яркость окна видеоплеера, не системную настройку. После закрытия плеера прежняя системная яркость должна оставаться прежней. Проверить поведение на RMX5303: текущая реализация использует яркость окна, но пользователь заметил нежелательное изменение.
2. **Видимые уровни жестов.** При свайпах яркости и громкости показывать шкалу с текущим уровнем. В настройках видео дать переключатель «Показывать уровни при свайпах»; при выключении жесты продолжают работать без шкал. Правая шкала отражает громкость самого видео, отдельно от системной.
3. **Покадровая перемотка свайпом.** Горизонтальное движение по видео должно позволять точно выбирать кадр, с показом времени и кадра во время жеста. Проверить точность на файлах с разной частотой кадров и поведение при отпускании.
4. **Недавно воспроизведённые видео.** Отдельный список в видеомедиатеке, упорядоченный по времени последнего просмотра, с сохранённой позицией и возможностью очистить историю.
5. **Кнопка «Продолжить последнее».** Один тап открывает последнее воспроизводившееся видео с сохранённой позиции. Если файл удалён или доступ к нему исчез, показать понятное сообщение и предложить выбрать другое видео.
6. **Непрерывное воспроизведение при переходе в другие приложения.** При Home и открытии другого приложения, включая YouTube, видео Vako Music должно оставаться в маленьком окне и продолжаться до явной паузы, остановки или закрытия окна пользователем. Проверить обработку жизненного цикла Android и конкуренции за аудиофокус; отдельно проверить возврат из маленького окна.
7. **Растянуть изображение по размеру экрана.** Добавить режим заполнения всей области просмотра с понятным переключением между вписыванием, растягиванием и заполнением с обрезкой краёв. Сохранять выбранный режим для следующего просмотра.
8. **Масштабирование щипком.** Двумя пальцами плавно увеличивать и уменьшать видео; при увеличении позволять перемещать изображение по экрану и быстро возвращаться к исходному масштабу. Жест не должен мешать перемотке одним пальцем.

Версия 0.17.0 реализует этот список. На RMX5303 проверены открытие тестового видео, появление истории и кнопки продолжения, переход в системное маленькое окно после Home и неизменность системного значения яркости после свайпа (57 до и после). Визуальную плавность масштабирования, точность перехода к отдельному кадру и одновременное воспроизведение с YouTube ещё нужно проверить вручную на разных видео. Тестовый файл и запись истории удалены после проверки.
